GearWin - Complete PC Care

PC를 유지 관리하고 정리하며 개선하기 위한 완전한 도구 모음.

Windows 11용 무료 오픈소스 유지 관리 및 최적화 도구로, 사용자가 PC를 빠르고 깨끗하며 안전하게,
완전히 자신의 통제하에 유지하는 데 필요한 모든 것을 한 곳에 모으기 위해 만들어졌습니다 - 더 이상
수십 개의 개별 도구를 뒤지거나 Windows 레지스트리를 수동으로 편집할 필요가 없습니다.

앱은 9개의 탭으로 구성되어 있습니다:

* 홈 - 한눈에 보는 PC 개요: 시스템 상태 점수(추세 스파크라인과 S.M.A.R.T. 디스크 상태 배지 포함),
  빠른 유지 관리 작업, 디스크 공간 분석, 실시간 처리량 그래프가 있는 네트워크 연결 상태.

* 업데이트 및 앱 - 앱, Windows, 드라이버 업데이트를 여러 신뢰할 수 있는 출처에서 한 번에 검색하고 일괄 설치하며, 필요 없는 Windows 구성 요소를 제거하거나
  추천 앱을 한 번에 설치하세요.

* 정리 및 성능 - 사무, 게임 또는 얼티밋 성능 모드를 켜고, RAM을 즉시 확보하며(실제 전/후 수치 표시), 임시 파일과 캐시를 정리하고, Windows와 함께 시작되는
  항목을 관리하세요.

* 상태 및 복구 - 시스템 파일(SFC/DISM), 디스크(CHKDSK), WinRE를 검사하고 복구하며, 레지스트리를 안전하게 정리하고(변경 전 자동 백업), 디스크 상태를
  시간에 따라 추적하세요.

* 보안 및 개인정보 - Windows Defender 빠른 검사를 실행하고, 방화벽 규칙과 열린 포트를 검토하며, Microsoft 원격 분석을 차단하고, 브라우저 암호를
  로컬에서 관리하고, 네트워크(DNS, hosts)를 한 번에 초기화하거나 조정하세요.

* 게임 및 멀티미디어 - Steam/Epic/GOG/Ubisoft/Xbox 라이브러리를 실행하고, 게임별 GPU/게이밍 프로필과 런처 캐시 정리를 지원합니다. 디스플레이, 오디오, 카메라/마이크 점검, 코덱 감지, 일괄 변환이 가능한 동영상/오디오 변환기도 제공합니다.

* Windows 설정 조정 - Windows 인터페이스/성능/개인 정보 보호 관련 수십 가지 조정 항목을 한 번의 클릭으로
  전환, 원래 값으로 안전하게 복원, 사용자 지정 마우스 오른쪽 버튼 클릭 메뉴 항목, 저장하고 즉시
  전환할 수 있는 이름이 지정된 또는 파일 기반 설정 프로필.

* 백업 및 보고서 - 보고서(PDF/TXT, 진단 ZIP, 배터리 보고서, 문제 보고 번들)를 내보내고 복원 지점, 레지스트리 백업, 드라이버 백업을 한곳에서 관리하세요.

* 시스템 및 도구 - '내 장치'에서 하드웨어 전체 분석을 확인하고, 원클릭 전체 유지 관리, Windows 도구 모음, WSL, USB 기록 등의 도구를 사용하세요.

추가 기능: 빠른 작업(빠른 정리, 상태 확인, 실시간 CPU/RAM/네트워크 미니 팝업)이 있는 시스템 트레이
아이콘과 선택적으로 항상 표시되는 데스크톱 위젯, 라이트/다크 모드와 애니메이션 배경이 있는 21가지
시각적 테마, "Windows Classic" 및 "Microsoft PC Manager" 스킨, 첫 실행 시 Windows 표시 언어 자동 감지.

14개 언어(그리스어, 영어, 독일어, 프랑스어, 스페인어, 이탈리아어, 러시아어, 중국어, 일본어,
포르투갈어, 한국어, 터키어, 아랍어, 힌디어)를 완벽하게 지원하며, MIT 라이선스에 따라 무료로
배포됩니다. 일부 개별 기능은 자체 라이선스를 따르는 별도의 오픈소스 라이브러리에 의존합니다(이
설치 프로그램의 라이선스 페이지 참조) - 전체 세부 정보는 앱 자체의 도움말 > 라이선스 탭에 있습니다.

설치를 계속하려면 "다음"을 클릭하세요.
