GearWin - Complete PC Care

PC를 유지 관리하고 정리하며 개선하기 위한 완전한 도구 모음.

Windows 11용 무료 오픈소스 유지 관리 및 최적화 도구로, 사용자가 PC를 빠르고 깨끗하며 안전하게,
완전히 자신의 통제하에 유지하는 데 필요한 모든 것을 한 곳에 모으기 위해 만들어졌습니다 - 더 이상
수십 개의 개별 도구를 뒤지거나 Windows 레지스트리를 수동으로 편집할 필요가 없습니다.

앱은 8개의 탭으로 구성되어 있습니다:

* 홈 - 한눈에 보는 PC 개요: 시스템 상태 점수(추세 스파크라인과 S.M.A.R.T. 디스크 상태 배지 포함),
  빠른 유지 관리 작업, 디스크 공간 분석, 실시간 처리량 그래프가 있는 네트워크 연결 상태.

* 최적화 - 임시/불필요한 파일 정리, 시작 프로그램 관리, 전원 관리 옵션, 매주 예약된 유지 관리, 여러
  소스(Windows Update, Microsoft 업데이트 카탈로그, AMD/NVIDIA/Dell/SDIO)의 드라이버 업데이트.

* 시스템 상태 - 디스크/메모리/파일 시스템 상태 확인(SFC/DISM/CHKDSK), 자동 백업 및 복원 기록이 있는
  레지스트리 클리너, 카테고리별 디스크 공간 분석, 원클릭 "모두 수정" 버튼이 있는 완전한 PC Manager
  스타일 상태 확인.

* 네트워크 및 보안 - 네트워크 진단, 열려 있는/수신 대기 중인 포트, DNS 설정, Windows Defender,
  원격 분석 차단, 그리고 모든 개인 정보 보호 도구를 하나의 섹션에 모음.

* 추가 설정 - Windows 인터페이스/성능/개인 정보 보호 관련 수십 가지 조정 항목을 한 번의 클릭으로
  전환, 원래 값으로 안전하게 복원, 사용자 지정 마우스 오른쪽 버튼 클릭 메뉴 항목, 저장하고 즉시
  전환할 수 있는 이름이 지정된 또는 파일 기반 설정 프로필.

* 블로트웨어 제거 - 필요 없는 사전 설치 앱을 안전하게 제거(재설치 옵션 포함), winget을 통한 권장
  앱의 원클릭 설치.

* 고급 도구 - 전체 시스템 유지 관리, 선택적 Windows 기능, 중복 파일 찾기, "고스트" 장치 정리, 내장
  도구에 빠르게 액세스할 수 있는 Windows 도구 상자.

* 시스템 - PDF 내보내기가 포함된 전체 하드웨어/OS 세부 정보("내 장치"), 시작 프로그램/프로세스/서비스
  관리, 디스크 속도 벤치마크, 복원 지점.

추가 기능: 빠른 작업(빠른 정리, 상태 확인, 실시간 CPU/RAM/네트워크 미니 팝업)이 있는 시스템 트레이
아이콘과 선택적으로 항상 표시되는 데스크톱 위젯, 라이트/다크 모드와 애니메이션 배경이 있는 21가지
시각적 테마, "Windows Classic" 및 "Microsoft PC Manager" 스킨, 첫 실행 시 Windows 표시 언어 자동 감지.

14개 언어(그리스어, 영어, 독일어, 프랑스어, 스페인어, 이탈리아어, 러시아어, 중국어, 일본어,
포르투갈어, 한국어, 터키어, 아랍어, 힌디어)를 완벽하게 지원하며, MIT 라이선스에 따라 무료로
배포됩니다. 일부 개별 기능은 자체 라이선스를 따르는 별도의 오픈소스 라이브러리에 의존합니다(이
설치 프로그램의 라이선스 페이지 참조) - 전체 세부 정보는 앱 자체의 도움말 > 라이선스 탭에 있습니다.

설치를 계속하려면 "다음"을 클릭하세요.
