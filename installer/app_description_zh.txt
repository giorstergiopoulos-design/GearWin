GearWin - Complete PC Care

用于维护、清理和改善您的电脑的完整工具集。

一款适用于 Windows 11 的免费开源维护和优化工具，旨在将用户保持电脑快速、整洁、安全并完全掌控所需
的一切集中到一个地方 - 不再需要在数十个独立工具中寻找，也不必手动编辑 Windows 注册表。

应用分为 8 个标签页：

* 主页 - 一目了然地查看您电脑的概况：系统健康评分（附带趋势迷你图和 S.M.A.R.T. 磁盘健康徽章）、快速
  维护操作、磁盘空间分析，以及带有实时吞吐量图表的网络连接状态。

* 优化 - 临时/垃圾文件清理、启动项管理、电源计划、每周计划维护，以及来自多个来源的驱动程序更新
  （Windows Update、Microsoft 更新目录、AMD/NVIDIA/Dell/SDIO）。

* 系统健康 - 磁盘/内存/文件系统健康检查（SFC/DISM/CHKDSK）、带自动备份和恢复历史记录的注册表清理
  工具、按类别划分的磁盘空间分析，以及带一键"全部修复"的完整 PC Manager 风格健康检查。

* 网络和安全 - 网络诊断、开放/监听端口、DNS 设置、Windows Defender、遥测阻止，以及所有隐私工具集中
  于一个部分。

* 附加设置 - 数十项 Windows 界面/性能/隐私调整，一键切换，安全恢复到原始值，自定义右键菜单项，以及
  可保存并即时切换的命名或基于文件的设置配置文件。

* 移除预装软件 - 安全移除不需要的预装应用，并提供重新安装选项，还可通过 winget 一键安装推荐应用。

* 高级工具 - 完整的系统维护、可选的 Windows 功能、重复文件查找器、"幽灵"设备清理，以及带快速访问内置
  工具的 Windows 工具箱。

* 系统 - 完整的硬件/操作系统详情（"我的设备"）并支持 PDF 导出、启动项/进程/服务管理、磁盘速度基准
  测试，以及还原点。

附加功能：带快速操作的系统托盘图标（快速清理、健康检查、实时 CPU/RAM/网络迷你弹出窗口）和可选的常驻
桌面小组件、21 种视觉主题（含浅色/深色模式和动态背景）、"Windows Classic" 和 "Microsoft PC Manager"
皮肤，以及首次启动时自动检测您的 Windows 显示语言。

完全支持 14 种语言（希腊语、英语、德语、法语、西班牙语、意大利语、俄语、中文、日语、葡萄牙语、韩语、
土耳其语、阿拉伯语、印地语），并根据 MIT 许可证免费分发。部分单独功能依赖于各自许可下的独立开源库
（请参阅此安装程序的许可证页面）- 完整详情请参阅应用自身的 帮助 > 许可证 标签页。

点击"下一步"继续安装。
