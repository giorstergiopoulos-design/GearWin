GearWin - Complete PC Care

用于维护、清理和改善您的电脑的完整工具集。

一款适用于 Windows 11 的免费开源维护和优化工具，旨在将用户保持电脑快速、整洁、安全并完全掌控所需
的一切集中到一个地方 - 不再需要在数十个独立工具中寻找，也不必手动编辑 Windows 注册表。

应用分为 9 个标签页：

* 主页 - 一目了然地查看您电脑的概况：系统健康评分（附带趋势迷你图和 S.M.A.R.T. 磁盘健康徽章）、快速
  维护操作、磁盘空间分析，以及带有实时吞吐量图表的网络连接状态。

* 更新与应用 - 一次扫描即可从多个可信来源获取应用、Windows 和驱动程序的更新并批量安装；还可移除不需要的 Windows 内置组件，或一键安装推荐应用。

* 清理与性能 - 切换办公、游戏或卓越性能模式，立即释放内存（显示真实的前后数值），清理临时文件和缓存，并管理随 Windows 启动的项目。

* 健康与修复 - 检查并修复系统文件（SFC/DISM）、磁盘（CHKDSK）和 WinRE，安全清理注册表（每次更改前自动备份），并长期跟踪磁盘健康状况。

* 安全与隐私 - 使用 Windows Defender 进行快速扫描，查看防火墙规则和开放端口，阻止 Microsoft 遥测，在本地管理浏览器密码，并一键重置或调整网络（DNS、hosts）。

* 游戏与多媒体 - 您的 Steam/Epic/GOG/Ubisoft/Xbox 游戏库，支持启动、按游戏设置 GPU/游戏配置以及清理启动器缓存；检查显示器、音频和摄像头/麦克风，检测编解码器，并提供支持批量转换的视频/音频转换器。

* Windows 调校 - 数十项 Windows 界面/性能/隐私调整，一键切换，安全恢复到原始值，自定义右键菜单项，以及
  可保存并即时切换的命名或基于文件的设置配置文件。

* 备份与报告 - 导出报告（PDF/TXT、诊断 ZIP、电池报告、问题报告包），并在一处管理还原点、注册表备份和驱动程序备份。

* 系统与工具 - 在“我的设备”中查看硬件的完整分析，然后使用各种工具：一键完整维护、Windows 工具箱、WSL、USB 历史记录等。

附加功能：带快速操作的系统托盘图标（快速清理、健康检查、实时 CPU/RAM/网络迷你弹出窗口）和可选的常驻
桌面小组件、21 种视觉主题（含浅色/深色模式和动态背景）、"Windows Classic" 和 "Microsoft PC Manager"
皮肤，以及首次启动时自动检测您的 Windows 显示语言。

完全支持 14 种语言（希腊语、英语、德语、法语、西班牙语、意大利语、俄语、中文、日语、葡萄牙语、韩语、
土耳其语、阿拉伯语、印地语），并根据 MIT 许可证免费分发。部分单独功能依赖于各自许可下的独立开源库
（请参阅此安装程序的许可证页面）- 完整详情请参阅应用自身的 帮助 > 许可证 标签页。
